# Workshop cu criptografie

Aceasta activitate este gandita special pentru saptamana scoala altfel. Dupa ce m-am intors dintr-un schimb de experienta cu tema criptografiei, am decis ca subiectul este ideal pentru o activitate in scoala altfel.

Workshpul este structurat astfel:
1. Curs de 2 ore (in practica 3) in care se explica diverse chestii criptografice (substituii monoalfabetice, criptari simetrice, asimetrice, masina enigma, etc.), se face o mica introducere in Python, prin comparatie cu C++ si se face o demonstratie de criptare si decriptare cu RSA.
2. Mini concurs in care elevii au de deslusit mai multe provocari precum ghicitori, sudoku, caesar cipher, dar si un RSA (care nimeni nu tine minte sa-l faca de la curs, dar practic o sa explici din nou fiecarei echipe si astfel o sa inteleaca principiul de criptare asimetrica)

Acest workshop a fost sustinut in anul scolar 2024-2025 si 2025-2026 de catre mine ca activitate voluntara.
In folderul Server gasim niste siteuri facute cu flask, practic baza din spatele platformei cu care elevii pot interactiona in timpul mini concursului. In folderul EscapeRoom se gasesc niste materiale ce trebuie printate, dar si niste povesti pentru atmosfera.
